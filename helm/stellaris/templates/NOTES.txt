Signing in
  On its first start on an empty volume, the server's init container creates the society
  "{{ .Values.society.name }}"{{ with .Values.society.citizens }} with {{ range $i, $c := . }}{{ if $i }}, {{ end }}{{ $c.name }}{{ end }}{{ end }}. Sign in with GitHub as {{ join ", " $github.users }}.
  The OAuth app's authorization callback URL must be {{ $url }}/auth/github/callback.
{{- else }}

Your user token
  On its first start on an empty volume, the server's init container creates the society
  "{{ .Values.society.name }}"{{ with .Values.society.citizens }} with {{ range $i, $c := . }}{{ if $i }}, {{ end }}{{ $c.name }}{{ end }}{{ end }}, and writes your user
  token, shown nowhere else, to /data/initial-user-token. Read it, keep it, then delete the file:

    kubectl -n {{ $ns }} exec deploy/{{ $name }} -c server -- cat /data/initial-user-token
    kubectl -n {{ $ns }} exec deploy/{{ $name }} -c server -- rm /data/initial-user-token
{{- end }}

Open the board
{{- if .Values.ingress.enabled }}
    {{ $url }}
{{- else }}
    kubectl -n {{ $ns }} port-forward svc/{{ $name }} {{ .Values.server.service.port }}:{{ .Values.server.service.port }}
  then open {{ $url }}{{ if not $github.enabled }} and enter the token{{ end }}.
{{- end }}

Connect a runner
  Turns run on runners, on the machines where the Claude Code and Codex CLIs and their logins are.
  Start one there with STELLARIS_SERVER_URL set to an address of this server it can reach:

    STELLARIS_SERVER_URL={{ $url }} stellaris-runner

  It prints a code and a link; approve it on the board under runners. It keeps the token approval
  gives it in its data directory and connects with it from then on.

Before an upgrade, pause the society with the board's Pause switch and let running turns end, then
resume after it.
