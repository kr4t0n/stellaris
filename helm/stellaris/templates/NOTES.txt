Connect a runner
  Turns run on runners, on the machines where the Claude Code and Codex CLIs and their logins are.
  Start one there with STELLARIS_SERVER_URL set to an address of this server it can reach:

    STELLARIS_SERVER_URL={{ $url }} stellaris-runner

  It prints a code and a link; approve it on the board under runners. It keeps the token approval
